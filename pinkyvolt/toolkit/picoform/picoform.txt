Simple static tool that can be hosted anywhere, all it needs is picoform.html file.

It reads URL parameter which is Base64 encoded json object.
Json object example:

{
  "title": "Life Expectancy Increase",
  "items": [["select=Board","Uno=1024","Mega=4096"],["number=Areas","min=1","max=10","value=1"]],
  "result": "'x'+Math.round($1/$2/2*10)/10+' times'"
}

Based on this parameter it creates interactive form with items listed in items array.
Items array contains lits of subarrays.
 - Each subarray has first element dedicated for type and name of item.
 - Subsequent elements are configuration values for that element.
 - For Select type these are possible options with Name=Value.
 - For Number input it should be Max/Min etc.

Last value is result - it is a formula where $1, $2, ... etc are item values in order they appear in  items array.

tO Encode JSON to BASE64:
  let _s = JSON.stringify(yourJSObject);
  let _b64 = btoa(_s);
URL Encode (Standard):
  let res = encodeURIComponent(_b64);
URL Encode (RFC 4648):
  function toUrlSafeBase64(base64) {
      return base64
          .replace(/\+/g, '-')
          .replace(/\//g, '_')
          .replace(/=+$/, ''); // Remove padding
  }

### Better encoding
```
    // Using lz-string library
    import LZString from 'lz-string';

    const largeJson = JSON.stringify({ users: [{ id: 1, name: "Alice" }, { id: 2, name: "Bob" }] });

    // Encode & Compress
    const compressedUrlParam = LZString.compressToEncodedURIComponent(largeJson);
    // Yields a highly compressed, completely URL-safe string

    // Decode & Decompress
    const originalJson = JSON.parse(LZString.decompressFromEncodedURIComponent(compressedUrlParam));
```
